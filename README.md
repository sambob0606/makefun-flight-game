Skyline Courier — a complete offline flight game. Fly a little red mail plane over a golden-hour valley in chase view: three sorties (an 8-ring course, a gusty 10-ring valley run on a fuel budget, and a precision landing on runway 09), lit instruments with speed and altitude tapes, a compass ribbon and an artificial horizon, a flight model with stalls, gusts, fuel and hull damage, and engine sound synthesised in code. Keyboard, mouse and touch controls; no network, no dependencies.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To hand the entry in the way the grader does: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
